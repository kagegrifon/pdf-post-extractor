# Отправления — печать фрагментов

Офлайн-PWA: принимает пачку PDF-бланков Почты России и собирает PDF для печати —
таблица реквизитов (отправитель, получатель, трек) и фрагменты с QR, маркой и штрихкодом
для вырезания. Фрагменты переносятся из исходного PDF без растеризации, поэтому качество
на бумаге ограничено только принтером.

Файлы обрабатываются в браузере и никуда не отправляются.

Ссылка на работающее приложение [https://kagegrifon.github.io/pdf-post-extractor](https://kagegrifon.github.io/pdf-post-extractor)

## Печать

Печатайте **в масштабе 100%** («Фактический размер»), не «По размеру страницы» —
иначе драйвер пересэмплирует штрихкод.

## Разработка

    npm install
    npm run dev        # dev-сервер (service worker в dev не работает)
    npm run lint       # линтер (Biome)
    npm test           # тесты; тесты на реальных бланках идут, только если есть data/expected.json
    npm run build      # сборка в dist/
    npm run preview    # проверка собранной версии, включая офлайн

Реальные бланки кладите в `data/` — папка в `.gitignore`, в репозиторий не попадает.

## Выпуск обновления

1. Поднять `version` в `package.json` (patch — исправление, minor — новая возможность,
   major — несовместимое изменение) и влить изменения в `main`. Job **Version** проверяет,
   что версия выросла: на PR — относительно целевой ветки, на push в `main` — относительно
   прежнего `main`; без этого деплой не запустится. Локально: `node scripts/check-version.mjs`.
2. Workflow **CI** (`.github/workflows/ci.yml`) прогонит линтер, тесты и сборку, после чего
   job **Deploy to GitHub Pages** встанет в ожидание: откройте запуск во вкладке Actions →
   *Review deployments* → отметьте `github-pages` → *Approve and deploy*.
   Повторно выкатить `main` можно через *Run workflow* у workflow CI.

Ручная выкладка на любой другой статический хостинг: `npm run build` и содержимое `dist/`
(для подкаталога — `BASE_PATH=/имя-подкаталога/ npm run build`).

Открытые приложения проверяют обновление при запуске, при возврате к вкладке и раз в час.
Если файлы не загружены, новая версия включается сама (страница перезагрузится); если пачка
уже загружена — появится плашка «Доступна новая версия», обновление по кнопке. Обычная
перезагрузка вкладки новую версию не включает. Хостинг не должен кэшировать `sw.js` надолго
(GitHub Pages — 10 минут, это нормально).

Какая версия открыта — подпись внизу страницы: `Версия X.Y.Z (хэш коммита)`. Что лежит
на хостинге — `<адрес сайта>/version.json` (service worker его не кэширует). Хэши
различаются — вкладка ещё на старой версии.

## Раскладка

Пресеты — `src/presets.ts`. Число рядов считается автоматически из размера листа,
полей и размера фрагмента. Новый формат бланка — новый объект в `src/template.ts`.

Поддерживаемые бланки (определяются по размеру страницы):

- конверт 220×110 мм — одна вырезка (QR, марка, штрихкод, трек);
- бандероль ф.7-б на A5 — две вырезки: марка с QR и штрихкод с треком; на листе они идут
  друг под другом, у каждой своя линия реза.
